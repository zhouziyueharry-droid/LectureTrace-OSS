## 边界

- 这是四页功能验收，不是全课程召回率评估。第 32/50 页是否在视频出现还未独立确认；不声称算法找回所有页面。
- 几何候选不是同页身份的绝对证明。批注、局部裁剪、相同模板、动画或画面过少特征可能导致漏配/误配。客户端应查看图片核对关键匹配。
- “完整单元”仅指现有 section 的全部已分配 T 转写，ASR 仍可能有错，话题可能跨单元。摘要 available 不等于语义无遗漏。
- 新工具已通过标准客户端；已运行的桌面 MCP 进程仍需重新加载才会发现新工具。本轮未强制重启用户客户端。
- 首次查询每张截图提取特征；内存缓存上限 256 图，跨很多课程可能淘汰重算。不提供持久化索引、全库图片查询或服务器端 PPT 渲染接口。
